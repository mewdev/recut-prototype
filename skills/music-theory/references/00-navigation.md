## Rule

Load 1–3 files. If a request needs more, narrow it — pick the dominant question first.

## Typical order for "make this cut more musical"

1. `song-form-and-sections.md` — know what each candidate section is *for*
2. `hooks-and-highlights.md` — identify what must survive a short edit
3. `cut-points-and-cadences.md` — check the actual boundary quality (needs `../assets/chord-notation.md` to read the map's chords)
4. `energy-arcs-and-density.md` — check the sequence's overall shape
5. `phrase-boundaries-and-groove.md` — only if the cut needs to land inside a segment, not at its edge
